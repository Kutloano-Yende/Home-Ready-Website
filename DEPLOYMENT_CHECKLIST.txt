CONTACT FORM SETUP (CRITICAL!)

Your contact form needs a backend to work. Choose ONE:

┌─ FORMSPREE (EASIEST) ─────────────────────────────────────────────────────┐
│ 1. Go to https://formspree.io                                             │
│ 2. Sign up (free)                                                         │
│ 3. Create new form                                                        │
│ 4. Copy your Form ID                                                      │
│ 5. In HomeReadyLanding.jsx, find:                                        │
│    <form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">    │
│ 6. Replace YOUR_FORM_ID with your actual ID                             │
│ 7. DONE - Forms now work!                                                 │
└─────────────────────────────────────────────────────────────────────────────┘

SUPPORT & TROUBLESHOOTING

Issue: npm: command not found
Fix: Install Node.js from https://nodejs.org

Issue: Port 3000 already in use
Fix: npm run dev -- --port 3001

Issue: Tailwind styles not showing
Fix: rm -rf node_modules && npm install

Issue: Form not submitting
Fix: Make sure Formspree ID is correct
